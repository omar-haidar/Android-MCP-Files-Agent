# عميل الذكاء الاصطناعي (Ai Agent) 🤖

[English Version (النسخة الإنجليزية)](README.md)

تطبيق أندرويد تجريبي مصمم للتفاعل مع نماذج **Google Gemini** والدمج مع **بروتوكول سياق النموذج (MCP)** لتنفيذ مهام متقدمة مثل إدارة الملفات.

## ⚠️ حالة المشروع
**ملاحظة:** هذا المشروع مخصص **لأغراض التجربة فقط** وهو حالياً **قيد التطوير ببطء شديد**. يعتبر هذا المشروع بمثابة مساحة لاختبار قدرات الذكاء الاصطناعي الجديدة على منصة أندرويد، وقد يحتوي على أخطاء أو ميزات غير مكتملة.

## 🚀 المميزات
- **تكامل Gemini:** دردشة سلسة مع نماذج مثل Gemini 3.1 Flash.
- **دعم MCP:** دعم تجريبي لبروتوكول Model Context Protocol للسماح للذكاء الاصطناعي بتنفيذ إجراءات محلية (مثل عمليات الملفات).
- **عرض Markdown:** عرض الردود بتنسيق أنيق باستخدام مكتبة Markwon.
- **إعداد سهل:** واجهة بسيطة لضبط مفتاح الـ API الخاص بـ Gemini.

## 🛠 التقنيات المستخدمة
- **اللغة:** Java
- **الواجهة:** Android ViewBinding & Material Design 3
- **الشبكات:** OkHttp
- **تنسيق النصوص:** Markwon
- **الواجهة البرمجية:** Google Generative AI API (إصدار v1beta)

## 📋 كيفية الاستخدام
1. قم بعمل Clone للمستودع.
2. افتح المشروع باستخدام Android Studio.
3. قم ببناء وتشغيل التطبيق على جهازك أو المحاكي.
4. احصل على مفتاح Gemini API من [Google AI Studio](https://aistudio.google.com/app/apikey).
5. أدخل المفتاح في إعدادات التطبيق.
