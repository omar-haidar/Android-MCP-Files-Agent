# Ai Agent 🤖

[Arabic Version (اللغة العربية)](README_AR.md)

An experimental Android application designed to interact with Google's **Gemini AI** models and integrate with the **Model Context Protocol (MCP)** for advanced tasks like file management.

## ⚠️ Project Status
**Note:** This project is strictly for **experimental purposes** and is currently under **slow development**. It is a playground for testing new AI capabilities on Android and may contain bugs or incomplete features.

## 🚀 Features
- **Gemini Integration:** Seamlessly chat with models like Gemini 3.1 Flash.
- **MCP Support:** Experimental support for Model Context Protocol to allow the AI to perform local actions (e.g., file operations).
- **Markdown Rendering:** Beautifully formatted responses using the Markwon library.
- **Easy Setup:** Simple UI to configure your Gemini API Key.

## 🛠 Tech Stack
- **Language:** Java
- **UI:** Android ViewBinding & Material Design 3
- **Networking:** OkHttp
- **Markdown:** Markwon
- **API:** Google Generative AI API (v1beta)

## 📋 How to Use
1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on your device/emulator.
4. Obtain a Gemini API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
5. Enter the key in the app's settings.
